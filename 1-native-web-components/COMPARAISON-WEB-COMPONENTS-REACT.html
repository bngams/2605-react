🔄 Web Components Natifs vs React

Tableau Comparatif des Concepts et Syntaxes

📦 Création d'un composant

Web Components Natifs React
Classe héritant de HTMLElement

class MyComponent extends HTMLElement

Enregistrement avec customElements.define()

class HelloWorld extends HTMLElement {
  constructor() {
    super();
  }
}

customElements.define('hello-world', HelloWorld);
Fonction ou Classe React

Fonction retournant du JSX ou classe React

function HelloWorld() {
  return <p>Hello, World!</p>;
}

export default HelloWorld;

🎨 Rendu (affichage)

Web Components Natifs React
connectedCallback()

Appelé quand le composant est ajouté au DOM

Utilise innerHTML ou shadowRoot.innerHTML

connectedCallback() {
  this.innerHTML = `<p>Hello!</p>`;
}
Return JSX

Le composant se rend automatiquement

Retourne directement du JSX

function MyComponent() {
  return <p>Hello!</p>;
}

📥 Props / Attributs

Web Components Natifs React
getAttribute() + observedAttributes

Attributs HTML récupérés manuellement

static get observedAttributes() {
  return ['name'];
}

attributeChangedCallback(name, oldVal, newVal) {
  if (name === 'name') {
    this.render();
  }
}

render() {
  const name = this.getAttribute('name');
  this.innerHTML = `<p>Hello, ${name}!</p>`;
}

// Utilisation:
// <hello-world name="Alice"></hello-world>
Props automatiques

Props passées en paramètre de fonction

Re-rendu automatique si props changent

function HelloWorld({ name }) {
  return <p>Hello, {name}!</p>;
}

// Utilisation:
// <HelloWorld name="Alice" />

🎭 Styles encapsulés

Web Components Natifs React
Shadow DOM

Encapsulation native avec attachShadow()

Styles vraiment isolés

constructor() {
  super();
  this.attachShadow({ mode: 'open' });
}

render() {
  this.shadowRoot.innerHTML = `
    <style>
      p { color: blue; font-weight: bold; }
    </style>
    <p>Hello!</p>
  `;
}
CSS Modules / styled-components

Encapsulation par convention

Noms de classes uniques générés

import styles from './Hello.module.css';

function HelloWorld() {
  return (
    <p className={styles.text}>Hello!</p>
  );
}

// ou avec styled-components:
const Text = styled.p`
  color: blue;
  font-weight: bold;
`;

🔄 État (State)

Web Components Natifs React
Propriétés manuelles

État géré avec propriétés de classe

Re-rendu manuel nécessaire

constructor() {
  super();
  this.count = 0;
}

increment() {
  this.count++;
  this.render(); // appel manuel
}
useState Hook

État réactif avec hooks

Re-rendu automatique

function Counter() {
  const [count, setCount] = useState(0);

  return (
    <button onClick={() => setCount(count + 1)}>
      Count: {count}
    </button>
  );
}

🎯 Événements

Web Components Natifs React
addEventListener()

Événements DOM natifs

Attachement manuel dans connectedCallback

connectedCallback() {
  this.shadowRoot.querySelector('button')
    .addEventListener('click', () => {
      this.count++;
      this.render();
    });
}
Props d'événements (onClick, etc.)

Événements synthétiques React

Déclaratif directement dans JSX

function Counter() {
  const [count, setCount] = useState(0);

  return (
    <button onClick={() => setCount(count + 1)}>
      Count: {count}
    </button>
  );
}

🔗 Communication entre composants

Web Components Natifs React
Custom Events

Événements personnalisés globaux

Communication découplée

// Composant émetteur
document.dispatchEvent(
  new CustomEvent('countChanged', {
    detail: this.count
  })
);

// Composant récepteur
document.addEventListener('countChanged', (e) => {
  this.count = e.detail;
  this.render();
});
Props & Callbacks

Props parent → enfant

Callbacks enfant → parent

// Parent
function App() {
  const [count, setCount] = useState(0);
  return (
    <>
      <Counter onIncrement={setCount} />
      <Display count={count} />
    </>
  );
}

// Enfant
function Counter({ onIncrement }) {
  return (
    <button onClick={() => onIncrement(p => p + 1)}>
      Increment
    </button>
  );
}

🚀 Utilisation dans le HTML

Web Components Natifs React
Balises HTML personnalisées

Nom avec tiret obligatoire (standard W3C)

Utilisable partout (HTML pur, tout framework)

<hello-world name="Alice"></hello-world>
<click-counter></click-counter>
Composants JSX

PascalCase obligatoire

Uniquement dans un projet React

<HelloWorld name="Alice" />
<ClickCounter />

📊 Résumé des différences clés

Critère Web Components Natifs React
Standard Standard Web (W3C) Librairie JavaScript
Compatibilité Tous frameworks Écosystème React uniquement
Encapsulation Shadow DOM (native) Par convention (CSS Modules, etc.)
Réactivité Manuelle Automatique
Courbe d'apprentissage Plus verbeux, plus bas niveau Plus abstrait, plus simple
Tooling Vanilla JS possible Nécessite build (Babel, Webpack/Vite)
Écosystème Limité Très riche (hooks, libraries, etc.)

💡 Quand utiliser quoi ?

Web Components Natifs

  • Composants réutilisables entre différents frameworks
  • Widgets/plugins intégrables partout
  • Projets sans build complexe
  • Besoin d'isolation stricte des styles

React

  • Applications complètes avec UI complexe
  • Besoin de réactivité automatique
  • Écosystème riche (routing, state management, etc.)
  • Développement rapide avec tooling moderne
